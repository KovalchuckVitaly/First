# Linux Administration Notes

Этот репозиторий содержит мои конспекты, практические задания и вопросы для подготовки
к собеседованиям по Linux Administration и DevOps.

Цель проекта:

- систематизировать знания по Linux;
- закреплять теорию практическими экспериментами;
- тренироваться работать с Git и GitHub;
- подготовиться к техническим собеседованиям;
- создать собственную базу знаний по Linux.

## Structure

Каждый модуль содержит:

- `theory.md` — краткая теория;
- `practice.md` — выполненные практические эксперименты;
- `interview.md` — вопросы для подготовки к собеседованию;
- `summary.md` — основные выводы по теме.
