# Summary — Linux Filesystem

## Что я понял

Linux представляет файловую систему как единое дерево каталогов, начинающееся с `/`.

Путь может быть:

- абсолютным — начинается от `/`;
- относительным — разрешается относительно текущего рабочего каталога процесса.

Имя файла не является самим файлом.

Каталог хранит соответствие:

имя → inode

Inode содержит метаданные объекта и информацию о расположении его данных, но обычно не содержит обычное имя файла.

Hard link — это дополнительное имя для того же inode.

Symbolic link — это отдельный файл, который хранит путь к другому объекту.

Команда rm удаляет имя из каталога и уменьшает количество жёстких ссылок. Она не обязательно сразу уничтожает данные.

Данные файла освобождаются, когда:

на inode больше не остаётся жёстких ссылок;
файл больше не открыт ни одним процессом.

Если процесс держит удалённый файл открытым, файл может продолжать занимать место на диске.

Команда cp обычно создаёт новый независимый файл с новым inode.

Команда mv внутри одной файловой системы обычно изменяет запись каталога, поэтому inode остаётся прежним.

При перемещении между файловыми системами файл фактически копируется в новую файловую систему, после чего исходный объект удаляется.

Главная модель

Имя в каталоге
       ↓
     inode
       ↓
Блоки с данными

Для открытого файла:

Процесс
   ↓
Файловый дескриптор
   ↓
Открытый объект файла
   ↓
inode
   ↓
Данные

Команды модуля
# Показывает текущий рабочий каталог.
pwd
# Показывает подробную информацию о файлах вместе с inode.
ls -li
# Создаёт hard link.
ln source hardlink
# Создаёт symbolic link.
ln -s target symlink
# Копирует файл.
cp source destination
# Перемещает или переименовывает файл.
mv source destination
# Удаляет имя файла из каталога.
rm file
# Показывает удалённые, но всё ещё открытые файлы.
sudo lsof +L1
